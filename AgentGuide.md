# Ikuti perintah ini untuk mengenal dan menganalisa proyek ini

## Struktur Folder

- Proyek ini menggunakan framework Laravel 12 pelajari saja struktur folder yang ada di dalam folder web-app dan kegunaan folder-folder yang ada didalamnya

- Baca PRD.md sebagai panduan dalam pembuatan proyek

- Baca arsitektur.md sebagai pengetahuan seluruh arsitektur pada sistem ini

- Baca secara mendalam semua yang ada di dalam folder Http, Models, database, public, routes

- Informasi tambahan, web ini berbentuk SPA (Single Page Application)

## Aksi

- Setiap ada perubahan konfirmasikan dahulu ke saya jangan langsung generate
- Setiap perubahan atau pembuatan kode buatkan penjelasannya pada baris komentar di setiap kode atau functionnya
- Jangan gunakan boostrap, tailwinds, dan fillament
- Sebelum membuat fitur baru periksa dahulu apakah ada bug yang akan mengganggu fitur sebelumnya
